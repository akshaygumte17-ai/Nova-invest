NOVA INVEST — FRONT-END DEMO
============================

Files:
- index.html  Main website pages
- style.css   Responsive dark navy / green styling
- app.js      Demo navigation, local browser data, forms, and admin review

HOW TO RUN
1. Extract the ZIP folder.
2. Open the extracted folder in VS Code using File > Open Folder.
3. Open index.html, then use Live Server if installed; or double-click index.html to open in a browser.

IMPORTANT LIMITATIONS
This is a client-side learning prototype only. It uses browser localStorage and does not have a secure backend,
real user authentication, payment gateway, bank integration, or real withdrawals. Data can be edited by users
and must not be used for real money. Never enter real payment or bank details.
It does not promise or calculate a 2% daily return. Guaranteed high daily returns are a major financial risk signal.
For production use, engage qualified developers and legal/compliance professionals, and build a secure backend.
